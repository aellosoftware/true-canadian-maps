Before you install

You need a Linux x64 server, Docker Engine with Compose, a domain and internet access. Start with 4 CPU cores, 8 GB RAM and 40 GB free disk; detailed basemap extracts and retained releases can require considerably more storage.

The installer starts privately, prepares the database and basemap, and lets you create the first administrator before exposing Studio. Public map files remain public. Origin restrictions do not make them confidential.

Installation guide · Backups, upgrades and rollback

This preview supports Linux x64 with an internet-connected installation. ARM64 and disconnected installation have not been verified. Configure your own SMTP provider before enabling password recovery.
